# Challenges

Terminal behavior differs across Windows, macOS, and Linux. Special keys can arrive as multi-byte sequences, and redirected input should not be treated as an interactive keyboard. A local JSONL file can also contain private information, so protect or delete it after an authorized test.

The project intentionally does not solve global capture, stealth, persistence, encryption, or remote collection. Adding those features would change the safety boundary and the purpose of this exercise.
