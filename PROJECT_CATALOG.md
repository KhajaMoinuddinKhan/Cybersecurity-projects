# Project catalog

- [Network Traffic Analyzer](PROJECTS/beginner/01-network-traffic-analyzer)
  Reads PCAP files and reports protocol, host, port, and DNS activity.
- [Phishing URL Detector](PROJECTS/beginner/02-phishing-url-detector)
  Scores URLs with clear phishing heuristics and explains each score.
- [File Integrity Monitor](PROJECTS/beginner/03-file-integrity-monitor)
  Tracks file changes by comparing SHA-256 hashes with a saved baseline.
- [SIEM Dashboard](PROJECTS/intermediate/04-siem-dashboard)
  Displays synthetic security events in a local Flask and SQLite dashboard.
- [Threat Intelligence Aggregator](PROJECTS/intermediate/05-threat-intelligence-aggregator)
  Imports IOC feeds into SQLite, removes duplicates, and searches stored indicators.
- [SSL/TLS Scanner](PROJECTS/intermediate/06-ssl-tls-scanner)
  Inspects a TLS connection, cipher, and peer certificate with certificate verification enabled.
- [Password Policy Auditor](PROJECTS/intermediate/07-password-policy-auditor)
  Compares a simple password-policy file with a visible baseline.
- [Docker Security Audit](PROJECTS/intermediate/08-docker-security-audit)
  Reviews saved Docker inspect data for common container configuration risks.
- [Web Vulnerability Scanner](PROJECTS/moderate/09-web-vulnerability-scanner)
  Runs passive security checks against localhost web pages.
- [Cloud Asset Inventory](PROJECTS/moderate/10-cloud-asset-inventory)
  Reviews a synthetic cloud inventory for public exposure and missing metadata.
